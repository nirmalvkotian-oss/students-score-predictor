# students-score-predictor

This is a simple machine learning web application built with Python and Streamlit. It uses a Linear Regression model to predict a student's exam score based on the number of hours they study.

## Features
- Interactive web UI using Streamlit
- Simple Linear Regression model using scikit-learn
- Slider input for study hours
